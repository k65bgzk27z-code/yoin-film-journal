# 余韻 — 私の映画記録

無料で使える、端末内保存型の映画記録アプリ。個人の感想・評価のサーバー送信、広告、解析、外部ライブラリはありません。映画情報を検索すると、作品名・作品IDと接続キーをTMDBに送信します。ポスターはTMDBの画像サーバーから読み込みます。アプリのコードは公開、利用者が入力する記録は各ブラウザ内に保存します。

## iPhone

HTTPSの公開URLをSafariで開き、共有メニューの「ホーム画面に追加」を選択。ホーム画面のアプリを開いて「オフライン準備完了」を確認してから利用します。以後はMacの稼働に依存せず記録できます。

Safariとホーム画面の保存領域は異なる場合があります。利用開始時からホーム画面版に統一してください。既存の記録は書き出したJSONを移行先で読み込みます。

## データ

MacとiPhoneの自動同期はありません。「バックアップを書き出す」でJSONをファイルに保存してください。ブラウザのデータ消去、アプリの削除、機種変更で端末内データを失う可能性があります。読み込みはIDで統合し、同じIDはバックアップの内容で更新します。

## 公開

GitHub Pagesでmainブランチのルートを公開。配布物はindex.html、sw.js、manifest.webmanifest、icon-192.png、icon-512.png、.nojekyllです。個人のバックアップJSONをリポジトリに追加しないでください。

## 映画情報・日本の配信サービス

「映画情報を接続」でTMDBの個人・非商用向けAPIキーまたは読み取り用アクセストークンを入力します。「この端末に接続キーを保存する」を選んだ場合だけブラウザ内に保存し、選ばなければ画面を開いている間だけ保持します。キーはバックアップや公開コードに含めません。ホーム画面版で別途接続が必要な場合があります。

作品名で検索し、公開年・ポスターを確認して候補を選択すると、作品情報・日本の劇場公開日・あらすじ・監督・上映時間・日本の配信先を保存できます。情報はTMDB、配信先はJustWatch（TMDB経由）。配信先は見放題・レンタル・購入・無料・広告付きに分類し、確認日を表示します。24時間を超えた情報は更新を促します。配信リストが空でも「配信なし」と断定しません。

既存記録の「映画情報を探す」で作品を紐付けられます。「情報を更新」は作品情報だけ更新し、評価・感想・ステータス・鑑賞日・自由メモを保持します。失敗時は前回の配信情報を保ち、今回取得に失敗したことを明示します。情報検索・更新には通信が必要です。保存済みテキストはオフラインで閲覧できますが、ポスターはオンライン時に読み込みます。
